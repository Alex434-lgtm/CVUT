Detailed Description

template<typename T>
class RBT< T >

Červeno-černý binární vyhledávací strom.

Strom podporuje hledání, vložení a odstranění v nejhorším případě v čase O(log n).

Obsahuje 2 Data membery std::unique_ptr<node<T>> root; což je kořen daného BST a std::size_t tree_size; který udavá počet uzlů v stromě

Typ T musí podporovat porovnání pomocí operátoru <.

◆ erase()

template<typename T>
bool RBT< T >::erase ( const T & key)

Odstraní zadaný klíč z červeno-černého stromu.

proměné které figurují v implementaci:

  • current – uzel odpovídající mazanému klíči,
  • x – uzel, který nahradil fyzicky odstraněný uzel,
  • parent – rodič uzlu x, hlavně když je x == nullptr,
  • c – původní barva fyzicky odstraněného uzlu,
  • temp – dočasný unique_ptr, který uchovává podstrom nebo následníka,

  • y – inorder následník při mazání uzlu se dvěma potomky. Popis průběhu funkce: Funkce nejprve najde uzel odpovídající zadanému klíči. Potom provede jednu ze tří variant běžného BST mazání:

    • uzel nemá levého potomka,
    • uzel nemá pravého potomka,
    • uzel má oba potomky.

    Při dvou potomcích je použit inorder následník, tedy nejmenší uzel v pravém podstromu. Pokud byl fyzicky odstraněný uzel černý, je následně zavolána funkce delete_fixup().

    Průběh funkce
    1. Najde uzel s požadovaným klíčem.
    2. Určí jeho potomky a původní barvu.
    3. Přesune vlastnictví podstromů pomocí std::move.
    4. Opraví nevlastnící ukazatele parent.
    5. Sníží tree_size.
    6. V případě odstranění černého uzlu zavolá delete_fixup().
    Parameters
    keyKlíč, který má být ze stromu odstraněn.
    Return values
    trueKlíč byl nalezen a odstraněn.
    falseKlíč se ve stromu nenacházel.
    Časová složitost
    O(log n) pro platný červeno-černý strom.

◆ validate()

template<typename T>
bool RBT< T >::validate ( ) const

Ověří všechny invarianty stromu.

Ověří všechny důležité invarianty stromu.

Kontroluje:

  • uspořádání binárního vyhledávacího stromu,
  • černou barvu kořene,
  • zákaz dvou sousedních červených uzlů,
  • shodnou černou výšku všech cest,
  • správnost ukazatelů na rodiče,
  • shodu skutečného počtu uzlů s tree_size.
Returns
true Pokud je struktura stromu platná.

Funkce postupně provede několik nezávislých validačních kontrol. Jakmile jedna z nich selže, okamžitě vrátí false.

Kontrolované vlastnosti
  • prázdný strom musí mít tree_size rovné nule,
  • kořen nesmí mít rodiče,
  • kořen musí být černý,
  • klíče musí splňovat pravidla binárního vyhledávacího stromu,
  • červený uzel nesmí mít červeného potomka,
  • ukazatele parent musí odpovídat skutečné struktuře stromu,
  • všechny cesty k nullptr musí mít stejnou černou výšku,
  • skutečný počet uzlů musí odpovídat tree_size.
Return values
trueStrom splňuje všechny kontrolované invarianty.
falseAlespoň jeden invariant stromu je porušen.
Časová složitost
O(n), protože validační funkce musí navštívit všechny uzly stromu.
