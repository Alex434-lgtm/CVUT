Detailed Description

template<typename T>
class RBT< T >

Červeno-černý binární vyhledávací strom.

Strom podporuje hledání, vložení a odstranění v nejhorším případě v čase O(log n).

Obsahuje 2 Data membery std::unique_ptr<node<T>> root; což je kořen daného BST a std::size_t tree_size; který udavá počet uzlů v stromě

template<typename T>
bool RBT< T >::validate ( ) const

Ověří všechny invarianty stromu.

Kontroluje:

  • uspořádání binárního vyhledávacího stromu,
  • černou barvu kořene,
  • zákaz dvou sousedních červených uzlů,
  • shodnou černou výšku všech cest,
  • správnost ukazatelů na rodiče,
  • shodu skutečného počtu uzlů s tree_size.
